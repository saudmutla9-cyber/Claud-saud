# تحدي إدارة المرافق · FM Challenge

لعبة مسابقة تفاعلية مباشرة (20 سؤال · 15 ثانية · حتى 30 لاعب) بواجهتين: شاشة المتحكم وشاشة اللاعب.

## التشغيل (على لابتوب متصل بنفس شبكة الواي فاي)
1. ثبّت Node.js (إصدار 18 أو أحدث) من nodejs.org
2. افتح مجلد اللعبة في الطرفية (Terminal / CMD) ونفّذ:
   ```
   npm install
   npm start
   ```
3. افتح على شاشة العرض: `http://localhost:3000/admin` — رمز الدخول: **2026**
4. تظهر صفحة "مرحباً بكم / Welcome" وفي أسفلها الباركود. اللاعبون يمسحونه بجوالاتهم ويسجّلون أسماءهم.
5. عند اكتمال الحضور اضغط **ابدأ اللعبة**.

> يجب أن تكون جوالات اللاعبين على نفس شبكة الواي فاي التي عليها اللابتوب.
> إذا كانت شبكة الضيوف معزولة، شغّل اللعبة على خادم سحابي (انظر أدناه).

## تحكم المتحكم
| الزر | الوظيفة |
|---|---|
| ابدأ اللعبة | يبدأ السؤال الأول |
| إنهاء السؤال | ينهي السؤال الحالي قبل انتهاء الوقت |
| السؤال التالي | ينتقل فوراً للسؤال التالي |
| انتقال تلقائي | عند التفعيل: يُعرض الترتيب 8 ثوانٍ ثم ينتقل تلقائياً. عند الإيقاف: ينتظر ضغطك |
| ✕ بجانب الاسم | إزالة لاعب من صفحة الانتظار |
| لعبة جديدة | تصفير النقاط مع إبقاء اللاعبين |
| مسح اللاعبين | حذف جميع اللاعبين |

## احتساب النقاط
- إجابة صحيحة = 500 نقطة + حتى 500 نقطة إضافية حسب السرعة (الحد الأقصى 1000 للسؤال)
- إجابة خاطئة أو انتهاء الوقت = 0
- ينتهي السؤال تلقائياً إذا أجاب جميع اللاعبين قبل انتهاء الوقت

## الإعدادات
| الإعداد | المكان |
|---|---|
| رمز المتحكم | متغير `ADMIN_PIN` أو أعلى ملف `server.js` |
| مدة السؤال / مدة عرض الترتيب / عدد اللاعبين | أعلى ملف `server.js` |
| الأسئلة والإجابات | ملف `questions.js` |
| العبارات التحفيزية | ملف `public/play.html` (قسم PHRASES) |

## التشغيل على خادم سحابي (اختياري)
ارفع المجلد إلى أي خدمة تدعم Node.js (مثل Render أو Railway) وأضف المتغيرات:
- `PUBLIC_URL` = رابط الموقع (مثال: `https://fm-challenge.onrender.com`) — ليُنشأ الباركود عليه
- `ADMIN_PIN` = رمز المتحكم
